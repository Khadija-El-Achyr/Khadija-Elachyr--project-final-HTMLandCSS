# Elle Choisit

A website created for the **16 Days of Activism** campaign, focused on the topic of **child marriage**.

## About

Elle Choisit ("She Chooses") raises awareness about child marriage and gives a voice to the girls affected by it. Visitors can read real stories of girls who were married young, and users can safely share their own stories and advice in a comfortable space.

## Features

- Real stories of girls who were married at a young age
- A space where users can share their own story and give advice
- A dedicated SOS page for people who need help
- Responsive design, works on phones and computers
- Simple and clean interface

## Built With

## Installation

```bash
git clone https://github.com/Khadija-El-Achyr/Khadija-Elachyr--project-final-HTMLandCSS.git
cd Khadija-Elachyr--project-final-HTMLandCSS
npm install
```

> Note: the `node_modules` folder is not included in the repository, so you must run `npm install` after cloning.

## Usage

To rebuild the Tailwind CSS after making changes:

```bash
npx @tailwindcss/cli -i ./public/css/input.css -o ./public/css/output.css --watch
```

Then open `index.html` in your browser.
